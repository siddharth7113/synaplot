# synaplot

Draw neural network architecture diagrams with LaTeX and TikZ.

synaplot is a rewrite of [PlotNeuralNet](https://github.com/HarisIqbal88/PlotNeuralNet)
as a Python package. It is early. There is no usable API yet, so these pages
cover only where the project came from and how it relates to the original.
